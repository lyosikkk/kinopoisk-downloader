# Kinopoisk Downloader

Браузерное расширение (Manifest V3) для автоматического поиска и скачивания торрент-раздач фильмов и сериалов непосредственно со страниц [Кинопоиска](https://www.kinopoisk.ru).

## Возможности

- **Интеграция в интерфейс Кинопоиска**: Кнопка «Скачать» автоматически размещается в блоке действий под основными кнопками («Смотреть онлайн», «Продолжить просмотр» или «Буду смотреть») с точным соответствием их размеров и стиля.
- **Встроенный поиск раздач**: Автоматический поиск торрент-файлов через зеркала Rutor и агрегатор Torlook без перехода на сторонние сайты.
- **Фильтрация сериалов по сезонам**: Распознавание отдельных сезонов и полных коллекций (паков) с изоляцией выдачи.
- **Фильтры по качеству и озвучкам**: Мгновенная сортировка по разрешению (4K, 1080p, 720p, 576p, 480p) и аудиодорожкам (Дубляж, MVO, AVO).
- **Разграничение типов контента**: Автоматическое разделение фильмов и сериалов — на страницах фильмов не выводятся сериалы, а на страницах сериалов отсекаются полнометражные спин-оффы.
- **Исключение неактивных раздач**: Полный отсев раздач с 0 сидами.
- **Прямая загрузка**: Скачивание `.torrent` файлов в один клик без перехода на сторонние трекеры.

## Архитектура и технологии

- **Manifest V3**: Соответствует актуальным стандартам безопасности Chrome Web Store.
- **Vanilla JavaScript & CSS**: Отсутствие сторонних тяжелых библиотек и фреймворков.
- **Background Service Worker**: Обработка сетевых запросов и обход CORS/блокировок через fallback-прокси.
- **Dynamic Content Injection**: MutationObserver для корректной работы при SPA-навигации Кинопоиска.

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/lyosikkk/kinopoisk-downloader.git
   ```
2. Откройте страницу управления расширениями в браузерах на базе Chromium (Chrome, Yandex Browser, Edge, Brave):
   - Chrome: `chrome://extensions/`
   - Яндекс Браузер: `browser://extensions/`
   - Edge: `edge://extensions/`
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите директорию с проектом.

## Использование

1. Перейдите на страницу любого фильма или сериала на Кинопоиске.
2. Под основной кнопкой воспроизведения появится кнопка **Скачать**.
3. Нажмите на кнопку — откроется меню со списком доступных раздач, отсортированных по количеству сидов.
4. Используйте фильтры сезонов, качества и озвучек для быстрого выбора подходящего релиза.
5. Нажмите **Скачать .torrent** для сохранения файла.
