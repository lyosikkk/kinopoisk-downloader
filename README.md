# Kinopoisk Downloader

Браузерное расширение, которое добавляет удобную кнопку «Скачать» прямо на страницы фильмов и сериалов Кинопоиска.

## Что умеет расширение

- **Поиск торрентов в один клик**: Под кнопкой воспроизведения появляется оранжевая кнопка «Скачать». Нажмите на неё, чтобы увидеть список раздач без перехода на сторонние сайты.
- **Фильтр по сезонам**: Выбирайте нужный сезон или скачивайте сериал целиком.
- **Выбор качества и озвучки**: Быстрый фильтр по качеству (4K, 1080p, 720p) и популярным озвучкам (Дубляж, Кубик в кубе, LostFilm и другим).
- **Только живые раздачи**: Мёртвые раздачи с 0 сидами автоматически скрываются.
- **Быстрое скачивание**: Нажмите кнопку — и `.torrent` файл сразу сохранится на ваш компьютер.

## Как установить

1. Перейдите в раздел [Releases](https://github.com/lyosikkk/kinopoisk-downloader/releases) и скачайте файл `kinopoisk-downloader-v1.0.0.zip`.
2. Распакуйте скачанный архив в любую папку на компьютере.
3. Откройте страницу расширений в вашем браузере:
   - В **Google Chrome**: перейдите по адресу `chrome://extensions/`
   - В **Яндекс Браузере**: перейдите по адресу `browser://extensions/`
4. Включите **Режим разработчика** (переключатель в правом верхнем углу).
5. Нажмите **Загрузить распакованное расширение** и выберите папку с расширением.

## Как пользоваться

1. Откройте любой фильм или сериал на Кинопоиске.
2. Нажмите оранжевую кнопку **Скачать** под плеером.
3. Выберите подходящее качество или сезон и нажмите **Скачать .torrent**.
