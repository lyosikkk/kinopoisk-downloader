# Kinopoisk Downloader

Браузерное расширение, которое добавляет кнопку «Скачать» прямо на страницы фильмов и сериалов [Кинопоиска](https://www.kinopoisk.ru) для удобного поиска и скачивания торрентов, а также выводит краткое описание при наведении на постер.

## Что умеет расширение

- **Предпросмотр описания при наведении**: Наведите курсор на постер любого фильма или сериала в разделах «Буду смотреть», списках или поиске — мгновенно появится аккуратное всплывающее окно с синопсисом, годом выпуска и рейтингом Кинопоиска без необходимости переходить на страницу произведения.
- **Мгновенный поиск раздач для фильмов и сериалов**: Под кнопкой воспроизведения появляется оранжевая кнопка «Скачать». При клике открывается встроенное меню со всеми доступными торрентами прямо на странице Кинопоиска без перехода на сторонние сайты.
- **Удобная фильтрация фильмов**: Быстрый подбор нужной версии фильма по качеству изображения (4K UHD, 1080p, 720p, 576p, 480p) и озвучке (профессиональный дубляж, студийный многоголосый перевод MVO, авторские переводы AVO).
- **Специальные фильтры для сериалов**: Автоматическая группировка раздач по сезонам — возможность выбрать конкретный сезон (1 сезон, 2 сезон и т.д.) или скачать весь сериал целиком одним паком.
- **Только живые раздачи**: Нерабочие торренты с 0 сидами автоматически скрываются из списка.
- **Скачивание .torrent в один клик**: Нажмите кнопку — и `.torrent` файл сразу сохранится на ваш компьютер.

## Как установить

### Шаг 1. Скачайте и распакуйте архив
1. Перейдите в раздел **[Releases](https://github.com/lyosikkk/kinopoisk-downloader/releases)** на GitHub.
2. Скачайте **последнюю версию ZIP-архива** из блока **Assets**.
3. Распакуйте архив в любую удобную папку на компьютере.

### Шаг 2. Включите расширение в браузере
1. Откройте страницу управления расширениями в браузере:
   - В **Google Chrome**: перейдите по адресу `chrome://extensions/`
   - В **Яндекс Браузере**: перейдите по адресу `browser://extensions/`
   - В **Microsoft Edge**: перейдите по адресу `edge://extensions/`
2. Включите **Режим разработчика** (переключатель в правом верхнем углу страницы).
3. Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) и выберите папку, в которую распаковали архив.

![Страница управления расширениями браузера](screens/Расширения.png)

## Как пользоваться

1. Наведите курсор на постер фильма или сериала в любом списке Кинопоиска (например, «Буду смотреть») для просмотра сюжета.
2. Откройте страницу нужного фильма или сериала на Кинопоиске.
3. Нажмите оранжевую кнопку **Скачать** под плеером.
4. Выберите подходящую раздачу и нажмите **Скачать .torrent**.
